SQL Server 2000, 2008R2, 2012, 2014 (AlwaysOn) administration. Provided 24x7 on-call Sybase/Informix production support. Sybase ASE database administration, supporting Kondor and KGR software. Informix and Sybase server replication and disaster recovery configuration.

Informix data extraction and conversion from source, creating transformations and loading into target servers. Informix Dynamic Server 12.10 administration using dbaccess, onstat, onmonitor, load, unload, dbimport, dbexport, dbschema, adding dbspaces and chunks to dbspaces. MySQL and PostgreSQL server administration. Backup and restore strategies, performance and tuning on all database technologies. Capacity planning, problem analysis and reporting. Incident and problem solving using CA Service Desk.
