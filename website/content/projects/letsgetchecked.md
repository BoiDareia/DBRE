Senior DBA at a home healthcare platform, managing the full spectrum of AWS database services across production environments.

**AWS RDS:** Migration of RDS SQL Server databases from 2016 to 2019 engine. Usage of DMS to migrate between MySQL to RDS MySQL, RDS MySQL to Redshift, and others. Architecture and implementation of HA/DR solutions for SQL Server databases running on RDS. Established database standards for operations, upgrades, migrations, and onboarding new applications. Implemented cloud security models with data masking and encryption methodologies, establishing appropriate end-user access control levels. Day-to-day operations and management of enterprise-level production databases in the cloud, including performance analysis, query tuning, database application design, data modelling, and developer support.

**AWS Redshift and Aurora:** Established database standards for operations, upgrades, migrations, and onboarding new applications and clients. Implemented database technology policies and procedures for maximum systems uptime with WLM and other Redshift tools. Day-to-day operations and management of an enterprise-level production Cloud Data Warehouse.

**Others:** Created Jenkins jobs for CI/CD automation for database deployment, Lambda functions updates, and more. Managed Jira board and created automation rules. Managed GitHub repositories, developed code, and managed branches.
