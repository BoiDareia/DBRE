What started as a Raspberry Pi running a few containers evolved into a full home infrastructure stack. The Ultimate Home Server is a self-hosted setup built on Linux, orchestrated with Docker, and backed by PostgreSQL for anything that needs reliable data persistence.

Home Assistant sits at the centre, managing smart home devices, automations, and monitoring. Alongside it runs a self-hosted photo management solution — because trusting cloud providers with personal memories is not the desenrasca way.

The entire stack is designed with the same principles applied to production environments: proper backups, container isolation, resource monitoring, and the ability to rebuild everything from configuration files.
