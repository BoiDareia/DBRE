ARPILF is a Portuguese IPSS (Instituição Particular de Solidariedade Social) that had been running on a dated Joomla installation for years. The site was slow, difficult to maintain, and the content management workflow was a bottleneck for the small team of volunteers.

The rebuild involved a complete migration to Hugo with Tailwind CSS for styling, giving the organisation a fast, accessible, and modern web presence. DecapCMS was integrated so that non-technical staff could update content through a friendly editor without touching code or deployments.

CI/CD pipelines were set up to automate the build and deployment process — push to the repository and the site updates itself. Beyond the website, the project included full IT management for the institution: email, infrastructure, and ongoing support.
