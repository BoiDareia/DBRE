First full DBRE role at an AI training data company, spanning SQL Server on-premises, Azure SQL Database, and SRE team responsibilities.

**SQL Server:** Design and maintenance of database solutions. Identifying, maintaining, and auditing database standards, best practices, and processes. Database installation and configuration (2000–2016 and Azure SQL versions). Design, configure, and maintain HA/DR solutions (AlwaysOn, FCI, Log Shipping, Replication). Performance tuning and system optimisation.

**Azure SQL Database:** Migration of SQL Server databases from on-premises to Azure IaaS/PaaS. Architecture and implementation of HA/DR solutions for SQL Server databases running on Azure. Established database standards for operations, upgrades, migrations, and onboarding new applications. Cloud security models with data masking and encryption. Day-to-day operations of enterprise-level production databases in the cloud, including SQL code review, performance analysis, query tuning, database application design, data modelling, and developer support. Strategic design and consultancy for cloud database services (Azure SQL, PostgreSQL, and CosmosDB).

**SRE Team:** Managed incidents, tracked outages, and supported engineering teams. Managed Service Level Indicators and Objectives. Monitored systems, provided visibility and insights about services and environments. Established guidelines, dashboards, and alerts.
